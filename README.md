# AssetApp

Pythonで開発した、株式投資向けの資産管理アプリです。

## 概要

自身の株式投資の経験をもとに、保有銘柄や資産状況を管理することを目的として開発しました。

Pythonの学習と実践的なアプリ開発を兼ねて、機能の設計・実装・改善を段階的に進めています。

## 主な機能

- 銘柄の登録
- 保有株数・取得価格・現在価格の管理
- 評価損益・損益率の計算
- 保有銘柄の一覧表示
- 評価損益ランキング
- 銘柄検索
- ポートフォリオ全体の評価額計算
- 年間配当金の計算
- JSON形式によるデータの保存・読み込み

## 使用技術

- Python
- JSON
- Git
- GitHub
- Visual Studio Code

## ファイル構成

- `main.py`：アプリのメイン処理
- `storage.py`：JSON形式のデータ保存・読み込み
- `history/`：Day1〜Day21の開発履歴
- `data/`：アプリのデータ保存先（GitHub公開対象外）
